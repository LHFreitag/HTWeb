# Transferência internacional — Google (Firebase / Analytics)

- **Papel**: Operador
- **País/Região**: ⚠ conferir a região do Firestore no console (se `southamerica-east1`, os dados ficam em São Paulo; Hosting/Auth e suporte global podem tratar dados nos EUA)
- **Finalidade**: hospedagem, banco de dados, login, armazenamento, estatística opcional
- **Enquadramento**: EUA sem decisão de adequação → Art. 33, II, "b" (Cláusulas-Padrão, Res. 19/2024 Anexo II) ⚠ verificar se o adendo de dados do Google Cloud já inclui as cláusulas brasileiras; se não, registrar a lacuna
- **Medidas suplementares**: TLS, criptografia em repouso do Google, regras de acesso por papel
- **Transparência**: Política de Privacidade v2026-11-23, seção 3
